# nexo_ui

UI widgets, state builders, and utility extensions for nexo.

Part of the [nexo](https://github.com/DoolotbekovSultan/nexo) toolkit.

## Installation

```yaml
dependencies:
  nexo_ui: ^0.1.0
```

Or use the umbrella package:

```yaml
dependencies:
  nexo: ^0.1.0
```

## Usage

```dart
import 'package:nexo_ui/nexo_ui.dart';
```
