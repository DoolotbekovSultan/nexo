# nexo_errors_hive

Hive failure mapper for nexo_errors.

Part of the [nexo](https://github.com/DoolotbekovSultan/nexo) toolkit.

## Installation

```yaml
dependencies:
  nexo_errors_hive: ^0.1.0
```

Or use the umbrella package:

```yaml
dependencies:
  nexo: ^0.1.0
```

## Usage

```dart
import 'package:nexo_errors_hive/nexo_errors_hive.dart';
```
