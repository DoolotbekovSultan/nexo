# nexo_core

Shared foundational types (NoParams, NexoUseCaseAnnotation, NexoAsyncState) for nexo packages.

Part of the [nexo](https://github.com/DoolotbekovSultan/nexo) toolkit.

## Installation

```yaml
dependencies:
  nexo_core: ^0.1.0
```

Or use the umbrella package:

```yaml
dependencies:
  nexo: ^0.1.0
```

## Usage

```dart
import 'package:nexo_core/nexo_core.dart';
```
