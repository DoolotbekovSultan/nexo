# nexo_logger

Abstract logger interface and Talker adapter for nexo.

Part of the [nexo](https://github.com/DoolotbekovSultan/nexo) toolkit.

## Installation

```yaml
dependencies:
  nexo_logger: ^0.1.0
```

Or use the umbrella package:

```yaml
dependencies:
  nexo: ^0.1.0
```

## Usage

```dart
import 'package:nexo_logger/nexo_logger.dart';
```
