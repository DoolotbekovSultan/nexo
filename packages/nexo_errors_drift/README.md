# nexo_errors_drift

Drift/SQLite failure mapper for nexo_errors.

Part of the [nexo](https://github.com/DoolotbekovSultan/nexo) toolkit.

## Installation

```yaml
dependencies:
  nexo_errors_drift: ^0.1.0
```

Or use the umbrella package:

```yaml
dependencies:
  nexo: ^0.1.0
```

## Usage

```dart
import 'package:nexo_errors_drift/nexo_errors_drift.dart';
```
